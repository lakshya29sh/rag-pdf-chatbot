# PDF Chatbot using RAG

An AI-powered chatbot capable of answering questions from uploaded PDF documents using Retrieval-Augmented Generation (RAG).

## Features
- PDF Upload
- Semantic Search
- AI Responses
- Streamlit Interface

## Tech Stack
- Python
- LangChain
- FAISS
- Streamlit
- OpenAI API

## Future Improvements
- Multi-PDF Support
- Voice Input
- Chat History
